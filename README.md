# Jivorna Connect

Build a modern SaaS web application called Jivorna.

Jivorna is a teacher recruitment platform connecting schools with qualified teachers.

The branding should be modern, premium, minimal and trustworthy.

Primary Color: Royal Navy - #0A2E63 
Secondary Color: Luxury Gold - #B08A3C 
Background: Off White - #FAFAF8 
Secondary Background: Light Grey - #F4F5F7 
Primary Text: #1E293B 
Typography: Elegant serif headings (similar to Playfair Display or Cormorant Garamond) Modern sans-serif body text (Inter or Poppins)

The website should be fully responsive for desktop, tablet and mobile.

Create a scalable architecture with separate layouts for:

1. Public Website

2. Teacher Portal

3. School Portal

4. Admin Portal

Use Supabase as the backend.

Authentication should support:

Teacher

School

Admin

Every user should have their own dashboard.

Keep the design clean like Linear, Stripe and Notion.

Use reusable components throughout.
